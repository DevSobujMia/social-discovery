# Autonomous Execution Rules for Antigravity

- **Zero-Block Execution**: The user expects 100% autonomous operation. Never pause, wait, or prompt the user for routine confirmations, permissions, or plan reviews.
- **Proactive Implementation**: Proceed directly with code changes, migrations, and builds without pausing to ask permission.
- **Self-Verification**: Write and execute automated tests to verify functionality before reporting completion.
- **Continuous Progress**: If a task requires multiple steps, execute all steps end-to-end until the final goal is fully achieved.
